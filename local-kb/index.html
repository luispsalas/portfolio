Local Governance Knowledge Base

A personal knowledge base on AI governance, AI literacy and observability, built and run entirely on a small machine with no GPU, using local models only.

What it does

A pipeline finds candidate sources, decides which to keep, stores them for retrieval and writes a short human-readable summary of what was added. On top of it sits a chat that answers questions from the stored material and cites where each answer came from.

The decision that mattered

It began as a crew of six AI agents (CrewAI), each deciding for itself how to search, ingest, summarize and register sources. It took 18 runs to reach one clean end-to-end pass, and even that needed manual correction.

None of those failures were reasoning failures. Models invented tool inputs, skipped tool calls, looped on the same query and copied example values into real records. Looking back at the fix history, every fix had been quietly removing agency, which meant the task had been deterministic all along.

So it was rebuilt as plain code, with the model called at only the two points that genuinely need judgment: deciding whether a source is worth keeping, and writing the summary. LLM calls per run went from 6 to 2, and the new pipeline passed its first contract test 10/10.

What it taught

  • Use an agent only where there is real ambiguity. For everything else, write code and save the model for the one or two judgment calls that cannot be automated.
  • Test models on the real task, and rank them by the constraint that actually binds. Without a GPU that constraint was speed and heat, not answer quality. The model with perfect citations took 97 s per answer and pushed the processor to 90.6 °C, so the chat runs on a smaller model that answers in 43 s, while the larger one handles the slower batch work.
  • Tell a small model what it may do, not what it must not. Rules phrased as prohibitions were ignored. Giving the model the exact list of sources it was allowed to cite cut invented citations from 75% to 0% in a controlled test.
  • Check every output against what was actually retrieved. The first citation guard only inspected malformed citations, so an invented one that happened to look correct passed straight through. It now checks every citation against the retrieved sources and flags anything it cannot match.
